# 功率模型与分配方法

本文说明 LYHrmer 在 2026 年维护版本采用的模型、约束和工程边界。它借鉴原仓库的转速平方损耗模型，以及香港科技大学 ENTERPRIZE 的功率模型与能量管理思路。物理关系与通用优化方法不作为本项目独创成果；具体来源见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 1. 先统一输入和测量位置

新模块使用每个电机的转速 `rpm` 和电调原始电流指令 `u`。接口中的 `u` 是协议数值，不直接等于安培；将一组拟合系数从一台底盘搬到另一台底盘前，必须确认协议量程、减速比和反馈定义一致。

| 量 | 含义 | 使用边界 |
| --- | --- | --- |
| `u` | 电调原始电流指令 | 限幅器的输入与输出；先进行各电机的电流限幅 |
| 电机反馈电流 | 驱动器上报的电流估计或反馈 | 按电机协议换算，用于离线建模时要与功率测量对齐 |
| 母线电流 | 直流供电支路电流 | 与同一测量位置的母线电压相乘，得到该支路输入功率 |
| `rpm` | 模型所选轴的转速 | 电机轴或减速器输出轴必须明确，不能混用 |
| `P` | 模型对应支路的输入功率，单位 W | 不默认等于裁判系统电池侧功率 |

电机电流、给定电流和母线电流是三个不同的量。尤其在低速大力矩时，不能把电调指令换算成电机电流后，直接乘母线电压当作底盘输入功率。

机械功率关系为：

\[
P_{\mathrm{mech}}=\tau\omega,\qquad
\omega=\frac{2\pi}{60}\,\mathrm{rpm}.
\]

如果选用电机轴，力矩也必须是电机轴力矩。如果选用减速器输出轴，就需要匹配输出轴转速、输出轴力矩以及一致的传动效率约定。不能把已乘减速比的力矩与减速前转速相乘。

若电流换算为 `I = c_I * u`，电机轴力矩近似为 `tau = K_t * I`，则对应电机轴转速的机械项系数为：

\[
k_{\mathrm{mech}}=K_t c_I\frac{2\pi}{60}.
\]

减速器输出轴建模需重新推导相应换算。这里的关系用于解释量纲，实际系数仍应通过设备手册与标定数据确认。

## 2. 每电机功率模型

第 `i` 个电机采用：

\[
P_i(u_i,n_i)=
k_{\mathrm{mech},i}u_i n_i+
k_{\mathrm{speed\_abs},i}|n_i|+
k_{\mathrm{speed\_sq},i}n_i^2+
k_{\mathrm{current\_sq},i}u_i^2+
p_{\mathrm{idle},i},
\]

其中 `n_i` 为该电机的 `rpm`。

| 系数 | 对应项 | 单位 |
| --- | --- | --- |
| `k_mech` | 电流指令与转速乘积形成的机械功率 | W / (raw command * rpm) |
| `k_speed_abs` | 与转速绝对值相关的损耗 | W / rpm |
| `k_speed_sq` | 与转速平方相关的损耗 | W / rpm^2 |
| `k_current_sq` | 与电流指令平方相关的损耗 | W / raw command^2 |
| `p_idle` | 分摊给该电机的静态损耗 | W |

原仓库使用的转速平方项在这里保留，ENTERPRIZE 模型中的转速绝对值项作为另一个可配置项引入。两项同时存在不代表拟合必然更好；激励不足时，它们可能高度相关。没有证据支持的项可以设为零。

损耗系数必须非负，静态损耗必须非负。机械项允许因 `u_i` 与 `n_i` 反号而为负。协议方向需要预先归一化，正常驱动时正向指令应对应正向转速。

如果只测得整个底盘的空载静态功率，应只分摊一次。不能给每个电机都加一份底盘总静态功率。电机数量、驱动器使能状态或测量支路改变后，这个分摊也需重新确认。

### 从力矩模型换算

ENTERPRIZE 公开说明采用：

\[
P_i=\tau_i\omega_i+k_1|\omega_i|+k_2\tau_i^2+c_i.
\]

在 `tau = c_tau * u` 且 `omega = 2*pi*rpm/60` 的同轴条件下：

\[
k_{\mathrm{mech}}=c_\tau\frac{2\pi}{60},\quad
k_{\mathrm{speed\_abs}}=k_1\frac{2\pi}{60},\quad
k_{\mathrm{current\_sq}}=k_2c_\tau^2,\quad
p_{\mathrm{idle}}=c_i.
\]

因此，其公开代码中的数值不能直接填入本模块的系数配置。`rpm`、`rad/s`、安培和原始指令量程之间的换算会同时改变多个系数。

## 3. 功率核算采用保守的正功率求和

各电机的预算占用为：

\[
P_{\mathrm{accounted}}=\sum_i\max(P_i,0).
\]

当某个电机处于制动状态，模型可能预测负功率。本实现不把这部分负功率抵扣其他电机的消耗，也不据此增加驱动预算。只有硬件确实支持回馈、测量位置明确且回馈效率经过验证时，才适合另行实现能量回收模型。

这是一种针对模型核算的保守处理，不能消除电流环延迟、测量误差、通信延迟和建模误差。预算仍需配置实际裕量，模型限幅结果不能等同于整车已经通过裁判系统功率验证。

## 4. 共同缩放与凸约束

先将每个电机请求指令限制到自身允许电流范围，得到 `u_bar_i`。再对这一组已经限流的指令采用共同缩放系数：

\[
u_{\mathrm{out},i}=s\bar u_i,\qquad 0\le s\le1.
\]

共同缩放保持已限流指令之间的比例和方向，且不会增加指令幅值。各电机最初的独立限流已经可能改变原始指令比例。共同缩放也不能保证所有地面条件下都精确保留车体轨迹；轮胎打滑、速度环差异和轮间负载分配仍影响实际运动。

在一个控制周期内固定测得转速，则：

\[
P_i(s)=A_i s^2+B_i s+C_i,
\]

\[
A_i=k_{\mathrm{current\_sq},i}\bar u_i^2\ge0,\quad
B_i=k_{\mathrm{mech},i}\bar u_i n_i,
\]

\[
C_i=k_{\mathrm{speed\_abs},i}|n_i|+
k_{\mathrm{speed\_sq},i}n_i^2+p_{\mathrm{idle},i}\ge0.
\]

需要解的问题为：

\[
\max_{s\in[0,1]}s
\quad\text{subject to}\quad
F(s)=\sum_i\max(A_i s^2+B_i s+C_i,0)\le P_{\mathrm{budget}}.
\]

每个二次项是凸函数，与零取最大值后仍凸，求和后 `F(s)` 仍凸。因此可行缩放系数构成一个区间，或者没有可行解。

### 为什么不能从零开始直接二分

制动时 `B_i` 可能为负，`F(s)` 可能先下降再上升，并不保证在整个 `[0, 1]` 上单调。零指令也可能保留转速损耗和静态损耗。

例如某个工作点可表示为：

\[
F(s)=\max(10s^2-8s+3,0).
\]

预算为 `2 W` 时，`s = 0` 不可行，`s = 0.4` 对应 `1.4 W` 却可行。把零指令当作必然可行的二分下界，会漏掉这种制动工作点。

采用的求解原则是：

1. 如果 `F(1)` 已经满足预算，保留全部已限流指令。
2. 在 `[0, 1]` 内寻找凸函数的最小值位置 `s_min`。
3. 如果最小功率仍超过预算，返回明确的不可行状态。
4. 如果存在可行解，在最小值右侧搜索最大的可行 `s`，保留尽可能多的请求输出。
5. 数值搜索使用固定迭代上限和容差，输出功率按最终命令重新核算。

在最小点右侧，凸函数是非递减的，因而这一区间适合二分。实现应保留可行的一侧作为结果，并处理区间端点、零损耗系数、全零命令和非有限输入。

### 不可行状态的含义

不可行表示：在当前转速、当前模型、当前预算以及 `0 <= s <= 1` 的命令集合中，没有满足约束的输出。不能用负判别式开方，也不能把无实根情况下的顶点力矩悄悄作为新制动命令。

若采取零命令作为故障回退，仍须报告不可行状态。由于模型包含转速损耗与静态损耗，零命令不代表模型估计功率必为零。是否进一步进入停车、制动或硬件断能流程，应由上层结合底盘类型与驱动器能力决定。

## 5. 预算管理与反馈降级

功率预算模块决定本周期可以使用多少功率；电机分配模块负责在此预算内限制请求。裁判系统功率上限来自接入层，本模块不把历史赛季的等级功率表作为当前规则。

| 模式 | 行为意图 | 预算边界 |
| --- | --- | --- |
| `NORMAL` | 按常规供电能力运行 | 受有效裁判功率上限、缓冲保护和配置上限约束 |
| `CHARGE` | 留出超级电容充电余量 | 在常规预算中减去配置的充电预留功率 |
| `BOOST` | 有限使用超级电容储能 | 额外功率同时受储能、预留能量、使用时长和硬件上限约束 |

超级电容额外可用功率可以由能量预算限制：

\[
P_{\mathrm{boost}}\le
\min\left(P_{\mathrm{cap,configured}},
\frac{\max(E_{\mathrm{cap}}-E_{\mathrm{reserve}},0)}{T_{\mathrm{horizon}}}\right),
\qquad T_{\mathrm{horizon}}>0.
\]

能量单位为 J，时长为 s，结果才是 W。`E_cap` 应采用与负载端预算一致的可用能量定义；若直接使用物理储能，还需要考虑转换效率和电容最低允许电压。由电容电压计算储能时，应使用已知电容量和有效电压区间，不能将电压百分比直接当作能量百分比。

裁判缓冲能量偏低时应降低预算，为模型误差和短时超调留下恢复空间。电容剩余能量与裁判缓冲能量是不同的反馈量，尽管都可参与能量管理，不能直接混加或无条件互换。

反馈是否可用至少需要同时判断连接状态、时间新鲜度、数值范围和错误状态：

- 裁判反馈陈旧时，使用配置的保守后备预算，不能继续无期限相信历史上限。
- 电容反馈陈旧或异常时，撤销依赖该反馈的增益与额外储能额度。
- 同时缺少有效裁判和电容反馈时，进入明确的降级状态。
- 电机反馈异常时，不再将旧转速视为当前精确测量；由接入层执行电机失联策略。
- 状态恢复时重新判断全部条件，避免一个过期样本立即解除保护。

时间戳与超时时长需采用同一时间基准。涉及秒的计算必须在浮点除法中完成，避免先做整数除法导致短周期时间间隔变为零。

## 6. 暂不自动在线更新模型

ENTERPRIZE 参考实现使用 RLS 对转速损耗和力矩平方损耗进行在线估计。该方法依赖可靠的实测功率及足够的激励；公式可递推并不表示当前数据一定能辨识参数。

本次实现采用显式配置的模型系数，暂不接入自动 RLS。后续引入前至少需要解决以下问题：

- 功率测量位于电池侧还是电机负载侧；电容充放电会使两者不同。
- 功率、反馈电流和转速必须按传感器延迟对齐，不能用当前指令拟合延迟的旧功率。
- 每个新测量只更新一次，不能在高频控制任务中把同一低频反馈重复当作独立样本。
- 失联、饱和、异常测量和无法识别的回馈区间需要拒绝更新。
- 参数非负约束、协方差数值稳定性、遗忘因子范围以及更新失败后的模型回退都需要明确实现。
- 缺少持续激励时，应冻结参数；不能以自身模型预测值替代实测功率，再据此宣布模型收敛。

## 7. 标定与结果归属

建议新采集记录至少包含时间戳、各电机原始指令、反馈电流、转速、功率测量位置、母线电压电流、电容状态、裁判上限以及工作模式。采集应覆盖静止、不同速度、不同负载和制动，不应只用单一转速拟合所有损耗项。

原仓库保留的数据、MATLAB 脚本和 PDF 是历史资料。本次没有重新核验数据采集者、设备、标定方法或全部实验条件，也没有将它们认定为 LYHrmer 亲自采集的数据。

新增示例参数和合成场景只能说明接口及算法行为。代码测试通过、模型预算满足和整车实测不超功率是不同层次的证据，发布结果时应分别写明。
